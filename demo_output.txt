== 5. the command reference ==

$ python3 chartroom.py --help
usage: chartroom.py [-h] [--version] [--store PATH] [--json] [--no-color]
                    {charts,course,tide} ...

Chartroom keeps a local inventory of the nautical charts aboard, the courses plotted from them and a log of observed tide heights.

positional arguments:
  {charts,course,tide}
    charts              chart inventory: add, list and remove charts aboard
    course              course plotting: plot, list, show and remove courses
    tide                tide table log: add, list and remove tide heights

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --store PATH          JSON store file (default: ~/.chartroom/store.json, or
                        $CHARTROOM_STORE)
  --json                print machine-readable JSON instead of the human-
                        readable table
  --no-color            disable ANSI colour (NO_COLOR is honoured as well)

examples:
  python chartroom.py charts add --number 1234 --title 'Solent Approach' --region Solent --scale 25000
  python chartroom.py charts list
  python chartroom.py course plot --name Solent --chart 1234 --waypoint Start:50.70,-1.20 --waypoint Mid:50.75,-1.40 --waypoint End:50.80,-1.60
  python chartroom.py course show --name Solent
  python chartroom.py tide add --station Portsmouth --time 2024-06-01T09:00 --height 2.4
  python chartroom.py tide list

store:
  the JSON store defaults to ~/.chartroom/store.json; use --store PATH or the
  CHARTROOM_STORE variable to keep demos and checks away from real data.

exit codes:
  0 success | 1 unreadable or unwritable store | 2 usage or validation error
[exit 0]
